= Configuration de laboratoire utilisée pour ce document
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
La figure ci-dessous présente une vue d'ensemble de la configuration du laboratoire utilisée. Deux systèmes HANA MDC mono-hôte sont utilisés pour démontrer les différentes opérations. Le système HANA BM1 est dédié à l'exécution des opérations de sauvegarde, de restauration et de récupération, tandis que le système HANA QM1 sert de système cible pour les opérations d'actualisation du système SAP. Les systèmes HANA sont déployés sur deux serveurs physiques et deux clusters ASA A30 à deux nœuds sont utilisés côté stockage. Le premier cluster héberge toutes les unités de stockage des systèmes HANA, et le second cluster est utilisé comme cible pour la réplication des sauvegardes.
